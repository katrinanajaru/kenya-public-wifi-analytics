# 🇰🇪 Kenya Public Wi-Fi Analytics Dashboard

## 📊 Project Overview

The Kenya Public Wi-Fi Analytics Dashboard is an interactive Power BI
business intelligence project designed to analyze public Wi-Fi usage
across different counties, hotspots, devices, users, and internet
service providers.

The project transforms raw Wi-Fi session data into meaningful
insights that can help stakeholders understand usage patterns,
network performance, user behavior, and geographic demand.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Monitor overall public Wi-Fi usage and activity
- Analyze user and device behavior
- Identify high-performing and underperforming hotspots
- Compare internet service provider performance
- Analyze Wi-Fi usage across different counties
- Identify peak usage periods
- Monitor connection success rates
- Support data-driven decisions around public Wi-Fi infrastructure

## 🗂️ Dataset

The dataset contains simulated public Wi-Fi usage data representing
users, devices, hotspots, internet providers, counties and Wi-Fi
sessions.

### Main Data Entities

- **Users** – User demographic and identification information
- **Devices** – Device type, operating system and browser information
- **Hotspots** – Public Wi-Fi hotspot locations
- **Counties** – Geographic information
- **Internet Providers** – Internet service provider information
- **Wi-Fi Sessions** – Session duration, bandwidth, speed,
  connection status and timestamps

> **Note:** The dataset is intended for analytical and portfolio
> purposes and does not contain confidential user information.

---

# 🏗️ Data Model

The project uses a structured data model connecting Wi-Fi sessions
with users, devices, hotspots, counties and internet providers.

The model allows users to drill down from overall performance into
specific geographic areas, hotspots, providers and device categories.
